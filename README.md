# ⚡ Cloudflare Workers 代码助手

> 专为 Cloudflare Workers 编辑页打造。手机长按选不中?点一下全选;删除要手打项目名?一键填入。

一个用于 Cloudflare Workers 代码编辑页的油猴脚本。把移动端最难用的两个操作——**选中代码**和**确认删除**——收敛成两次点击。


## 为什么需要它

在手机上管理 Cloudflare Workers 时,有两个非常烦人的问题:

- **编辑器里长按选不中代码**,没法全选、清空或复制,只能一段段删。
- **删除资源时弹窗要求手动输入项目名称**才能确认,手机上打字又慢又容易错。

这个脚本就是为了解决这两件事。

## 功能特性

| 功能            | 说明                                                |
| ------------- | ------------------------------------------------- |
| ☑️ **一键全选**   | 解决移动端长按无法全选的问题,兼容 Monaco / EditContext / textarea |
| ✅ **一键填入项目名** | 删除确认弹窗自动出现「一键填入」按钮,点一下自动填好名称                      |
| 🗑️ 一键清空      | 全选 + 删除,不用长按狂按退格键                                 |
| 📋 一键复制       | 完整读取编辑器代码到剪贴板                                     |
| 🩺 诊断面板       | 生成编辑器环境报告,方便排查问题                                  |
| 📱 移动端适配      | 大按钮、安全区适配、深浅色跟随系统                                 |

> 「一键填入」在 `dash.cloudflare.com` 的**所有页面**生效(Workers / Pages / KV / D1 等),不限于编辑器页面。

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 新建一个用户脚本,把本仓库的脚本代码完整粘贴进去。
3. 保存并启用脚本。
4. 打开 Cloudflare Workers 代码编辑页,右下角出现圆形按钮即安装成功。

脚本适配的页面:

- `https://dash.cloudflare.com/*`
- Cloudflare Workers 代码编辑页(编辑器位于跨域 iframe 中,脚本通过 `postMessage` 与 iframe 通信)

## 使用方法

### 编辑代码

点击右下角圆形按钮,竖向弹出四个功能按钮(离主按钮最近的是「全选」):

- **全选** —— 选中编辑器里的全部代码
- **清空** —— 一键删除全部代码
- **复制** —— 把全部代码复制到剪贴板
- **诊断** —— 查看编辑器环境信息,可一键复制诊断文本

### 删除确认一键填入

在 Cloudflare 后台删除 Workers / Pages / KV / D1 等资源时,如果弹窗出现「输入 xxx 以确认删除」这类提示,输入框旁边会自动出现橙色的 **「一键填入」** 按钮。点击后会自动填入要求的项目名称,删除按钮随即变为可点击。

## 实现说明

- **跨 iframe 通信**:顶层页面与主按钮负责交互,通过 `postMessage` 把指令发给编辑器 iframe,再由 iframe 内的适配器执行。
- **全选 / 清空**:优先使用 Monaco 编辑器 API,并兼容 VSCode Web 的 `EditContext`,保证在 Cloudflare 新版编辑器里可靠生效。
- **一键填入**:先用 `execCommand('insertText')` 模拟真人输入,失败时回退到原生 `value` setter 并派发 `input` / `change` 事件,确保 React 能识别值已变化。
- **运行时机**:`document-idle`,并通过轻量轮询适配控制台单页应用内跳转到编辑页的场景。

## 排查

如果「一键填入」按钮没有出现,可在浏览器控制台执行:

```js
__cfFillDebug()
```

它会以表格形式列出页面上每个输入框的占位符、可见性、禁用状态以及匹配到的值,便于判断是否识别到了确认弹窗。

诊断编辑器本身可点击工具菜单里的「诊断」按钮,查看 iframe 数量、编辑器类型等信息。
